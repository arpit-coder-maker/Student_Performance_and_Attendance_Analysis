# Student Performance and Attendance Analysis System

## Project Overview

The Student Performance and Attendance Analysis System is a Python-based project that analyses student academic performance and attendance records using CSV datasets.

The project uses Python libraries such as Pandas and NumPy to read, process, and analyse student data. It helps users identify top-performing students, low-performing students, attendance records, and individual student details.

## Features

- CSV File Selection: Choose between two available class datasets.
- Display Student Records: View the number of rows specified by the user.
- Student Data Analysis: Analyse student academic performance.
- Top Scoring Students: Display the top 5 students based on percentage.
- Low Scoring Students: Display the lowest 5 students based on percentage.
- Attendance Analysis: Calculate average attendance and identify students with attendance below 75%.
- Subject-wise Analysis: Calculate average marks in different subjects.
- Student Search: Find complete student details using their roll number.
- Behaviour Analysis: Display the count of different student behaviour categories.

## Dataset Description

The project uses two CSV files:

1. "CLASS10ASTUDENTS.csv"
2. "CLASS10BSTUDENTS.csv"

Each dataset contains student information with the following columns:

Column Name| Description

Roll No.| Student roll number

Name| Student name

Attendance %| Attendance percentage

English| English marks

Science| Science marks

Social Sc| Social Science marks

Math| Mathematics marks

Computer Sc| Computer Science marks

Total Mark| Total marks obtained

Percentage| Overall percentage

Behaviour| Student behaviour category
